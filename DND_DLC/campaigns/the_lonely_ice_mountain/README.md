# 🧊 The Lonely Ice Mountain

A frozen peak is hammering a village with supernatural storms. Scale the mountain and find out what's at the top.

| | |
|---|---|
| Difficulty | Hard |
| Level | Lv 4+ |
| Players | 2–4 |
| Reward | 120–280 gold · 350 XP |

## Encounters

1. **Base of the Mountain** *(combat)* — Dire Wolf Pack
2. **The Icy Ledge** *(interaction)* — CON or STR check to cross a treacherous ice shelf
3. **The Storm Elemental** *(combat)* — final boss at the peak
