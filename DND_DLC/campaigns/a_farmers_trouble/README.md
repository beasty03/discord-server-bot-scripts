# 🌾 A Farmer's Trouble

A goblin infestation has been raiding the local wheat fields every night. The desperate farmer sends you to clear out their cave.

| | |
|---|---|
| Difficulty | Easy |
| Level | Lv 1+ |
| Players | 1–4 |
| Reward | 15–45 gold · 100 XP |

## Encounters

1. **The Wheat Field** *(combat)* — Two Goblin Scouts (HP 18, AC 12)
2. **The Cave Entrance** *(interaction)* — DEX 10 check to sneak past the lookout; failure triggers a fight
3. **The Goblin Den** *(combat)* — Goblin Warchief and guards
