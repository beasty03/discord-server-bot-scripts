# 🏛️ The Mayor's Request

**Difficulty:** Easy | **Level:** 1+ | **Players:** 1–4 | **Reward:** 40–80 g / 120 XP

A goblin has been robbing travelers on the mill road outside Millvale. The mayor wants it dealt with.

## Encounters

| # | Type | Name | Notes |
|---|---|---|---|
| 1 | Combat | The Mill Road | Single goblin — low HP, easy opener |
| 2 | Interaction | The Cave Mouth | DEX DC 11 sneak past the wolf; fail = dire wolf fight |
| 3 | Interaction | The Back Chamber | WIS DC 20; fail triggers the secret encounter |
