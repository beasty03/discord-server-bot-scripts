# 🏚️ Beneath the Old Mill

A merchant has been kidnapped by kobold raiders hiding in tunnels beneath an old mill. Drop in and get him back.

| | |
|---|---|
| Difficulty | Medium |
| Level | Lv 2+ |
| Players | 2–4 |
| Reward | 150–300 gold · 280 XP |

## Encounters

1. **The Entry Shaft** *(combat)* — Kobold Sentries
2. **The Flooded Chamber** *(interaction)* — skill check to cross without alerting the garrison
3. **The Kobold Captain** *(combat)* — drops the 🗝️ Iron Key
4. **The Sealed Gate** *(choice)* — use the key or try to pick the lock
5. **The Prisoner Cell** *(combat)* — final fight to rescue the merchant

## Exclusive drops

| Item | Slot | Drop from | Effect |
|---|---|---|---|
